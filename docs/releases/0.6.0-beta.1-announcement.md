# uBixShepherd 0.6.0-beta.1: Shepherd now starts approved work on its own

uBixShepherd 0.6.0-beta.1 is out. Keep-going mode no longer waits for a client or for the
desk to act: it picks up approved work and keeps your run slots full, inside the caps you
set. Crook, Muster and the first merge-rule groundwork arrive with it.

## Highlights

- **Keep-going starts the work.** The daemon continues interrupted items and starts
  approved ones in rank order, held by spend, run, idle and end-of-day limits.
- **Ask Crook why.** `shepherd crook why` explains why Shepherd did, held or refused
  something, from a log of every verdict.
- **Muster tidies stale lists.** A pass over artifacts, lanes, runs, next-up items and
  questions tidies what is safe and undoable and raises the rest for you.
- **Approved checks stay put.** Lanes set approved check files aside, and `lane ship`
  refuses a branch that changes them.
- **Merge rules in shadow mode.** See what a merge rule would have done before you let it
  act; Shepherd records and never merges.
- **Hands-off for agents' git hooks.** Agents are told never to skip hooks, and a run seen
  doing so is flagged.

This is a beta. Interfaces may still change between betas, and every change is listed in
the changelog. Nothing in this release breaks existing use.

## Upgrade

- From a running install: press **Upgrade** in the web UI, run `shepherd update upgrade`,
  or use `/update upgrade` in `shepherd chat`.
- New install or reinstall: follow [INSTALL.md](<INSTALL_LINK>) or run `install.sh`
  from the repository.
- Store changes are forward-only; going back a version can mean a fresh store.

Archives are checksummed and signed with a keyless cosign bundle: see
[verifying a download](<VERIFY_LINK>).
