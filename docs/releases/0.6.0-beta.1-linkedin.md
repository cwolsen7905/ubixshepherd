uBixShepherd 0.6.0-beta.1 is out.

Shepherd now starts approved work on its own. Keep-going mode picks up the items you have approved and keeps your agent run slots full, inside the spend, run and time limits you set. This beta also adds a way to ask why Shepherd did, held or refused something, a tidy-up pass for stale lists, and a shadow mode that shows what a merge rule would have done before you let it act.

It is a beta, so interfaces may still change. Nothing in this release breaks existing use.

Release notes and downloads: <RELEASE_URL>

Next to Shepherd, we are working on uBixKelpie. It already reviews merge requests with AI and leaves its findings as review threads. We are building toward having it triage those threads and fix them. More when there is something to show.
