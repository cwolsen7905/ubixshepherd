Most of the time an agent spends waiting isn't waiting on hard problems. It's waiting for us to click something we already said yes to.

uBixShepherd 0.6.0-beta.1 closes that gap. Keep-going mode picks up approved work and keeps your agent run slots full, inside the spend, run and time limits you set. It adds no new authority: everything it starts was already approved by something else. When a round of fixes on a merge request doesn't close its open items, the next round moves to Claude Code instead of repeating the same attempt.

The release also adds `shepherd crook why` to see why Shepherd acted or held, Muster for tidying stale lists, and merge rules that run in shadow mode first. It is a beta, so interfaces may still change.

Next to Shepherd, we are working on uBixKelpie. It already reviews merge requests with AI and leaves its findings as review threads, and we are building toward having it triage those threads and fix them.
